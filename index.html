How to enable native Gemini Nano in Chrome:
  1. Use Google Chrome Canary or Dev (v127+).
  2. Enable chrome://flags/#prompt-api-for-gemini-nano (Enabled).
  3. Enable chrome://flags/#optimization-guide-on-device-model (Enabled BypassPerfRequirement).
  4. Restart Chrome and open chrome://components, ensuring Optimization Guide On Device Model is fully downloaded.

Client-Side Privacy Sandbox Architecture

Nano-WebMCP guarantees 100% offline-ready privacy:

  • Zero Server Relay: Prompts and responses never leave your device. There is no remote LLM proxy or analytics tracker.
  • Isolated Local Vault: The local_privacy_vault tool writes to your browser's local sandbox (localStorage) with client-only scoping.
  • Hardware Introspection: Queries are evaluated against standard W3C Web APIs (navigator.gpu, navigator.hardwareConcurrency) directly in the DOM thread.
  • Zero Cost: No OpenAI, Anthropic, or external API keys needed. Free and infinite client-side reasoning.
